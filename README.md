## О проекте
Студенческий проект по веб-разработке — лендинг, посвященный анатомии акцидентного шрифта Parmigiano Piccolo Pro. В проекте реализована сложная типографика, работа с SVG-графикой, позиционирование элементов и адаптивная верстка.

## Использование инструментов с искусственным интеллектом (ИИ)
В ходе работы над проектом использовались нейросети ChatGPT в качестве вспомогательного инструмента для:
*   Написания базовой структуры HTML и CSS-сетки (Flexbox).
*   Помощи в позиционировании сложных декоративных элементов (линии, круги, подписи).
*   Исправления синтаксических ошибок в коде.
*   Генерации шаблона данного файла README.md.

Весь визуальный дизайн выполнен самостоятельно в Figma. Код был адаптирован, проверен и доработан автором проекта.
